# 鼎新伺服器環境評估工具

此倉庫僅提供已編譯的 Windows 執行版本，不公開專案原始碼。

請從 [Releases](https://github.com/digiwinserver-art/Digiwin-Server-Environment-Assessment/releases/latest) 下載最新版本。

建議下載 `DigiwinServerEnvironmentAssessment-win.zip`，解壓縮後讓 EXE 與 `.exe.config` 保持在同一資料夾。

工具維持唯讀，不修改 SQL、IIS、登錄或 Windows 設定；不支援 Windows Server 2008 R2。
